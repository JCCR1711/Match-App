## Regla de actualizacion

Al cerrar un bloque de trabajo, registrar solamente decisiones, contratos,
evidencia de pruebas, riesgos y siguientes pasos. El codigo sigue siendo la
fuente de verdad de implementacion; esta memoria explica por que existe y que
debe verificarse.
